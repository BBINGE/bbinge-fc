# 원정 다득점 축떡 데이터 감사 기록

글: `/football-made-easy/away-goals-rule-abolition-uefa-data/` (2026-09-15 발행)

## 원자료와 집계 방법

- UEFA.com 경기 데이터(`match.uefa.com/v5/matches?competitionId={1|2|14}&seasonYear={연도}&limit=500&offset=`)에서 유러피언컵·UEFA 챔피언스 리그(1), 유러피언 컵위너스컵(2), UEFA컵·UEFA 유로파 리그(14)의 전 경기를 2026년 9월 15일 받았다. 경기 수 8,832 / 2,531 / 13,843. `seasonYear`의 기준 연도가 대회마다 달라 경기 날짜로 시즌을 다시 매겼다(6월 20일 이후 = 새 시즌, 시작 연도 표기).
- 같은 대회·시즌에서 1차전(`leg.number=1`)과 홈·원정이 뒤바뀐 2차전(`leg.number=2`)을 한 대결로 짝지었다. 총 9,371건. `leg`가 없는 같은 두 팀 경기가 2차전 뒤에 있으면 재경기로 봤다.
- **API의 `winner.aggregate.reason`은 사용하지 않았다.** 규정이 없던 1956년 대결(스포라-도르트문트, 재경기로 결정)에도 `WIN_ON_AWAY_GOAL`이 붙어 있어 소급 표기로 판단했다. 원정골 결정은 점수로 직접 계산했다: 합계 동점 + 원정골 수 차이 + 재경기 없음 + 승부차기 없음.
- 원정골 적용 기간: 컵위너스컵 1965-66, 유러피언컵 1967-68(데이터상 첫 원정골 결정: 발루르-죄네스 에슈, 글렌토란-벤피카), UEFA컵 1971-72(데이터 시작), 모두 2020-21까지. 인터시티스 페어스컵은 UEFA 공식 기록 밖이라 없다.
- 연장전 판단: 2차전 `score.regular`와 `score.total`이 다르거나 `score.penalty`가 있으면 연장전. 2014-15 레기아-셀틱은 몰수(0-2 → 3-0)라 regular/total이 달라 연장전 원정골 목록에서 제외해 35건.
