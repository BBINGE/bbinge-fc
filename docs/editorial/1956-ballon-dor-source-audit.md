# 1956 발롱도르 출처 감사

## 기록 패널·원고 후속 교정

- 운영자 원문의 세 묶음(팀 성적 / 개인 수상·기록 / 개인 스탯)을 복원했다. 매슈스 빨강·디스테파노 금색·코파 파랑을 되살리고 전역 h3 여백의 우선순위 충돌을 해결했다. 한 문장에 여러 대회와 해설을 섞지 않는다.
- 원문 연간 클럽 수치와 도움은 아래 대조 미완료 상태를 유지한다. 대신 확인된 시즌·대회별 세부 출전과 득점을 나열했다. 매슈스의 1956 A매치 5경기 1골은 RSSSF 경기 목록상 친선 2/0, 홈 챔피언십 2/1, 월드컵 예선 1/0으로 분해된다. 홈 챔피언십 출전 행은 1956년 경기이며 팀 우승 행의 1955-56 대회와 다르다.
- 디스테파노 유러피언컵 5골은 UEFA 상위 득점 기록상 공동 4위. 스몰 클럽 월드컵 RSSSF 경기별 명단·득점은 6경기 4골. 해당 페이지의 일부 팀 스코어/득점 진행 및 다른 선수 합계에는 불일치가 있으므로 원문의 스몰 클럽 월드컵 득점왕 항목은 확정하지 않았다.
- 상단 시즌 우승팀 모듈은 UEFA·RSSSF에서 유러피언컵 우승 레알, 준우승 랭스, 4강 밀란·히버니언을 확인했다. 후속 연도 관련 클럽·국가대항전 확장 규칙은 CONTENT_EDITORIAL_INTENT에 반영했다. 올림픽 등 다른 대회의 평가 반영 여부를 이번 글에서 추정하지 않았다.
- 줄리뉴 표기는 운영자 합의에 따라 브라질 / 이탈리아(수상 기록상 분류)의 두 줄로 바꿨다. 후자는 시민권 취득 확인이 아니다. 아래 이전 교정의 브라질 단독 표기 메모를 대체한다.
- 원고의 나는/내가는 필자는/필자가로 변경. 결말은 수상의 권위와 첫 수상자의 관계라는 해석을 유지하되, 득점·윙어의 기여·공로상 판단을 구분하는 논증으로 다듬었다.

## 발행 후 UI 교정

- 전체 랭킹은 국적 이력을 원국적→후속 국적 순으로 병기한다. 동시 보유의 법적 상태나 혈통·출생지만으로 이중국적을 단정하지 않는다. 기준 연도는 1956이다.
- 디스테파노(아르헨티나·스페인): 기존 UEFA source-11. 코파(폴란드·프랑스): 관세행정사협회의 국적증명서 해설(source-15). 시소브스키(폴란드·프랑스): Moselle Sport의 귀화 회고와 FFF 1951년 데뷔(source-16). 몬투오리(아르헨티나·이탈리아), 스키아피노(우루과이·이탈리아): Europeana·UEFA·Maglia Rossonera의 대표팀 시작 시기 교차 확인(source-17).
- 줄리뉴는 브라질로 표기하고 RSSSF의 Italy 분류는 awardCountry에 별도 보존한다. 이탈리아 시민권 취득을 확인하지 못했으므로 후국적을 만들어 넣지 않는다. 공개 각주에 두 분류의 차이를 밝힌다(source-18·source-1). 아래 최초 발행의 Italy 표기 보존 메모는 이 교정으로 대체한다.
- 피앙토니는 이탈리아계라는 이유만으로 국적을 추가하지 않는다. Calciomio의 2021년 회고는 1966년 장면에서 이중국적을 언급하지만 취득 시점을 특정하지 않아 1956년 표에 소급하지 않는다(https://www.calciomio.fr/dossier-la-diaspora-italienne-roger-piantoni-id-112262). 푸슈카시·코치시도 훗날의 스페인 이력을 당대 국적에 미리 넣지 않는다.
- 표 최소 너비를 제거하고 PC는 고정 열 비율, 모바일은 선수·점수 아래 국적/구단 또는 다섯 순위표를 배치한다. 두 표 24명 전체 값과 내부 스크롤·잘림을 380/768/1440px에서 검사한다.

- 후속 명시 지시로 레알은 흰 바탕·보라 사선, 랭스는 좁은 흰 양옆·붉은 중앙으로 조정했다. 영국·잉글랜드 배경은 기존 국기 SVG의 유니언잭·세인트조지 십자가를 우측에 사용하고 텍스트 구역은 단색으로 보호한다. 국기 프레임은 원본 비율(영국·프랑스4:3, 잉글랜드5:3, 스페인3:2)에 맞춰 여백을 제거하며 원본 도안을 변경하지 않는다.

- 운영자가 선수 아카이브의 간결한 표와 동일한 자산·정렬 사용을 재지시했다. 별도 배경 띠를 제거하고 국기를 라운드 칸에 분리했다. 행별 부연 메모는 렌더링하지 않으며 기존 본문과 데이터는 유지한다.
- 스페인 색면은 기존 legend-identity-spain과 동일한 CSS 규칙을 사용한다. 1956년 도안을 현대의 왕국 국기·우승별이 달린 대표팀 문장으로 바꾸지 않는다. 새로운 이미지 제작·다운로드 없음.
- 회귀 검수에 국기의 행 내부 위치·라운드 프레임·동일 텍스트 시작선·부연 메모 부재를 추가했다.

## 자산과 공개 범위

- 운영자 발롱도르.zip 발행 승인. 정확한 제목과 로고·썸네일·1/2/3.png 무변형 보존.
- 매슈스 사진은 FA컵이며 발롱도르 수상 사진이라고 쓰지 않는다. 다른 사진 촬영 시점은 추정하지 않는다. 실제 현대 발롱도르 로고는 브랜드 간판이지1956년 당시 그래픽이라는 주장이 아니다.
- A/B 외부 위험 신호 없음. 일반적 C 가능성으로 승인 자산을 교체하지 않는다. NO ACTION.
- 네이버 원문은 priorPublication 메타데이터로 연결하고 제작 과정 메모는 본문에 넣지 않는다.

- RSSSF의 France Football 제561호(1956-12-18) 전재: 기자16명, 배점5/4/3/2/1, 전체240점,24명. 데이터 검사는 개별 점수·동점 순위·각 순위표16장을 확인한다.

## 공유 자산과 후속 규칙

- 국가→대표팀→평가 기간 관련 클럽. 영국은 영국→구성국을 먼저 둔다. 매슈스4행·디스테파노3행·코파4행.
- 국기와 대표팀 문장은 별개. 기존 영국/프랑스/1945스페인 국기 재사용, 잉글랜드 세인트조지기 추가.
- Historical Football Kits 잉글랜드/블랙풀,1000logos 프랑스/스페인 시대 문장. 블랙풀 파일명1938은 도입 연도로 쓰지 않는다. 페이지는1952경 도입을 설명한다.
- 레알1941·랭스1931은 기존 검토 자산. 랭스SVG는 래스터 포함. 원본이 래스터인 문장을 새SVG로 위장하지 않는다.
- CSS는 원본을 변형하지 않고 여백·하단 출처 연도만 표시 영역에서 제외한다. 문장 자체 잘림은 화면으로 검사한다.
- historical-identities.json의 검토 years는1956만 허용. 다른 연도는 자동 연장하지 않는다. 선수 아카이브도 공유 자산·resolveHistoricalIdentity를 재사용할 수 있다. 기존 선수 글의 소급 개편은 이번 범위 밖이다.
- 새 원고 검수·전체 빌드 및380/768/1440px QA. 이미지·계층·24명 표·내부 앵커·가로 넘침·시상관 노출 및 index 검증. 자동 생성 today-football.json은 커밋 제외.
