# 1957-58 유러피언컵 베스트 11 발행 근거

- 성격: 공식 대회 베스트 11이 없는 시즌이라 1955-56·1956-57 편과 같은 삥이FC 회고 선정. 기준은 운영자 확정 "우승팀 우대·자료 편향 없이 대회 전체 활약".
- 명단 확정(운영자 대화, 2026-09-22): Claude가 등번호·출전·득점·실점 집계로 초안과 자리별 대안을 제시했고, 운영자가 "현안대로 가자"로 초안을 그대로 확정했다. 정해 달라고 올린 쟁점(밀란 1명, GK 알론소·부폰, 맨유 세 명 해석, 디스테파노 하프 배치)은 모두 초안 유지.
