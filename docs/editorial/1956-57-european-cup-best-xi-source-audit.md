# 1956-57 유러피언컵 베스트 11 발행 근거

- 성격: 공식 대회 베스트 11이 없는 시즌이라 1955-56 편과 같이 삥이FC 회고 선정. 기준은 운영자 확정 "우승팀 우대·자료 편향 없이 대회 전체 활약".
- 명단 확정 과정(운영자 대화, 2026-09-14): 초안(알론소 / 마그니니·마르키토스·번 / 무뇨스·에드워즈 / 줄리뉴·코파·디스테파노·바이올렛·코스티치)에서 운영자가 무뇨스를 빼고 디스테파노를 하프로 내려 헨토를 넣자고 제안. 테일러가 CF로 들어가 득점 1·2·3위가 모두 남고, GK를 베아라로 바꿔 4강 네 팀이 모두 포함되는 안으로 확정. 디스테파노 RH는 등번호가 아닌 필자 배치임을 본문·기록 기준에 명시.
- 표지: 운영자 표지 대기. 임시로 결승 H/L 썸네일(`/images/highlights/1956-57-european-cup-final-thumbnail.jpg`)을 `coverImage`로 지정. 운영자 표지가 오면 교체하고 읽기 동선 카드 이미지도 함께 바꾼다.
