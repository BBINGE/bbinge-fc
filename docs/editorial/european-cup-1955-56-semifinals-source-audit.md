# 1955-56 유러피언컵 4강 편집 기록

- 승인: 2026-09-10 운영자 “일단 올려서 발행까지 해봐 내가 보고 규칙 잡아줄께”. 이번 발행은 향후 고정 템플릿 확정이 아니다.
- 표지는 `유러피언컵.png` 네 토끼. 도판 3개와 표지 원본 PNG를 무변형 보존하고 같은 해상도의 WebP를 화면에 사용한다. 도판 내부 사진은 개별 크롭하지 않는다.
- 본문은 4강 1차전 / 4강 2차전 H2, 각 경기 H3. 두 합계 카드는 기존 시즌 로고·국기 데이터를 재사용한다. 왼쪽 팀 기준 점수와 실제 2차전 홈팀을 구분한다.
- 실제 시간순은 4월 4일 랭스-히버니언 → 4월 18일 히버니언-랭스 → 4월 19일 레알-밀란 → 5월 1일 밀란-레알.
- Le Monde 1956-04-06 보도: 코파 비판과 관중 반응, 르블롱 헤더 및 블리아르 득점. 기사에 있던 당시 결승 예정일은 실제 결승일과 달라 인용하지 않는다. 후반 피로에 대한 기자 판단을 객관적 측정값처럼 쓰지 않는다.
- Le Monde 1956-04-18 프리뷰: 랭스의 직전 생테티엔전 패배와 부상, 히버니언의 머더웰전 무승부. 종케 복귀 표현은 앞선 출전 기록과 충돌할 수 있어 생략한다.
- Cuadernos de Fútbol 2013 회고: 레알의 국내리그 상황과 1차전 공격/수비 평가, 2차전 수비 변화. 본문은 저자의 평가로 귀속한다. ‘같은 선발’ 서술은 실제 나바로/아티엔사 변경과 맞지 않아 사용하지 않는다. 랭스 관련 리그 우승팀 오기도 본문에 옮기지 않는다.
- 1차전 리알 5/6분, 디스테파노 62/63분 차이는 공개 기록 주석에 표시한다. RSSSF의 첫 경기 6/62분을 채택한다. 2차전 달몬테 골은 Maglia Rossonera와 CIHEFE 및 운영자 도판의 69/86분 PK를 사용한다. RSSSF에는 86/89분으로 적힌 다른 집계가 있어 2차전 시각의 단독 근거로 쓰지 않는다.
- 관중: 운영자 도판 레알-밀란 129,690명, Maglia Rossonera 120,000명 등 편차가 있어 본문 확정 수치 생략. 히버니언-랭스 44,941명은 경기 기록과 도판 일치.
- 코파의 글로바츠키 회고는 FFF가 재수록한 1998년 France Football 인터뷰로, 1954년 월드컵에 대한 기억이다. 1956년 골의 도움·세부 움직임 증거로 전용하지 않는다.
- 인물 원어/연도는 FFF(르블롱·블리아르·글로바츠키), 레알 공식 역사(리알·올센·호세이토), Maglia Rossonera(노르달·스키아피노), 아오스타 시 달몬테 생애 PDF를 대조했다. 달몬테 성명은 시 기록의 Giorgio Carlo Dal Monte, 생몰년 1931-1992.
- 원고 내 출처 링크에 자료별 범위 명시. 기존 첫 편 본문·사진과 미발행 결승 편은 수정하지 않는다.

## 검수
- npm run build 통과(177페이지). 외부 경기 API 접근 실패는 기존 캐시 fallback으로 처리됐고 자동 변경된 today-football.json은 발행 범위에서 제외했다.
- 대진 12개 기존 합계와 새 4강 2개 합계·결승 진출 라벨 시험 통과.
- Edge/Playwright 380·768·1440px: 원본 비율 표지, 이미지 로딩, 출처 앵커, 카드 텍스트, 문서 가로 넘침, 기록표 키보드 펼침 및 JS 없는 정적 페이지 통과. 도판 원본 4개 SHA256이 제공 파일과 일치.
- 재현: PLAYWRIGHT_CHANNEL=msedge 환경에서 node scripts/qa-european-cup-semifinals.mjs. 설치된 Chromium이 있으면 환경변수 생략 가능.

## 4강 진출팀 표 추가
- 표지 아래에 순위 없는 구단·국가·4강 진출 표. 초대 대회라 네 팀 모두 첫 진출이며 해당 시즌까지 누적 기준이다.
- 기존 승인 시즌 자산 재사용. 히버니언 엉겅퀴/HFC 문장은 https://www.worldsoccerpins.com/historical-crests-hibernian-fc 에서 구단 인쇄물용 과거 문장으로 확인했으나 시작 연도 미확정. 현대 SVG로 대체하지 않고 제공 JFIF 보존. 랭스는 기존 래스터 포함 SVG, 레알·밀란은 벡터 SVG. 국기 모두 기존 로컬 SVG.
