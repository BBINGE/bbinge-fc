# 1956-57 유러피언컵 4강 발행 근거

- 범위: 4강 1차전·2차전 네 경기와 결승 진출팀. 결승 H/L은 별도 후속 편이며 미발행 링크를 만들지 않는다.
- 저본: 운영자 네이버 글 223777328382의 4강 1차전·2차전 절과 운영자 제공 도판 3장(바탕화면 `1956_57_유러피언컵.png` 네 토끼 표지 966×966, `4강_1차전.png`·`4강_2차전.png` 966×1067). 1955-56 4강 편과 같이 원본 PNG를 `*-original.png`로 무변형 보존하고 같은 해상도 WebP를 화면에 쓴다. 대회 개요 도판은 1956-57 본선 편의 `cover.png`를 재사용한다. 형식은 1955-56 4강 편(4강 진출팀 표 → 1차전 H2·경기 H3 → 2차전 → 합계 카드 → 네 경기 기록표)을 따랐다.
- 기록 원장: UEFA 경기 데이터(`seasonYear=1956`의 Semi-finals 4경기, 경기별 `/lineups`), RSSSF `ec195657det`.

## 본문 근거

- 선발: UEFA 라인업. 피오렌티나는 4강 두 경기 선발 동일, 츠르베나 즈베즈다는 2차전에 골키퍼 베아라 등 교체. 맨유 1차전 10번 바이올렛, 2차전 10번 찰턴.
- 뮌헨 사고 여섯 명: 1차전 맨유 선발 번·콜먼·에드워즈·테일러·휠런·페그(위키백과 뮌헨 공항 사고).
- 올드 트래퍼드 첫 유러피언컵 경기: 위키백과 1956-57 맨유 시즌(유럽 홈경기 첫 세 경기 메인 로드)·올드 트래퍼드(첫 조명 경기 1957년 3월 25일)와 UEFA 경기장 데이터 대조.
- 찰턴: 1956년 10월 6일 리그 데뷔, 시즌 출전이 주로 바이올렛 자리였다는 위키백과 시즌 기사 서술.
- 유고슬라비아 구단 첫 4강, 이탈리아 구단 첫 결승: 시즌 데이터(1955-56 4강·결승 명단)에서 도출.
- 결승 장소 베르나베우: UEFA 시즌 회고(전년 여름 개최권 부여)와 경기 데이터.
- 인물 생몰년: 영어 위키백과 도입부(프리니 1932-2009, 몬투오리 1932-1998, 비르질리 1935-2016, 사르티 1933-2017, 베아라 1928-2014, 셰쿨라라츠 1937-2019, 미티치 1922-2008, 번 1929-1958, 찰턴 1937-2023)와 사이트 기존 병기.
- 개별 권리 신호 없음. 도판 속 사진은 운영자 편집물로 보존, C등급 조치 없음.
