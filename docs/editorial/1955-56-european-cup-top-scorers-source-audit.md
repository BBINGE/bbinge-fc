# 1955-56 유러피언컵 득점 순위 발행 근거

- 범위: 대회 최다 득점 순위(네 골 이상 9명)와 1위부터 공동 7위까지의 경기별 득점. 선수 이력은 베스트 11 편에 있어 반복하지 않고 연결한다.
- 저본: 운영자 네이버 글 223775749568 `7. 득점 랭킹`의 도판(`UEFA_챔피언스_리그_득점랭킹.png`). 운영자가 채팅에 붙인 이미지와 같은 도판을 원글에서 966×1144 원본 폭으로 받아 `public/images/archive/1955-56-european-cup-top-scorers/top-scorers.png`에 무변형 저장했다. 원글의 해당 절에는 본문 문장이 없어 원고는 새로 썼다.
- 기록 원장: UEFA 경기 데이터 `match.uefa.com/v5/matches?competitionId=1&seasonYear=1955`(29경기 득점자·시각)와 경기별 `/lineups`(선발 출전), RSSSF `ec195556det`(득점자 목록, 127골).

- 도판 순위·골 수는 두 자료와 모두 일치한다. 표기만 다르다: 도판 `펄로타슈`·`블리아드` → 사이트 기존 표기 `펄로타시`·`블리아르`. 표지 캡션에 같은 인물임을 밝혔다.
- 도판의 국적 칸은 디스테파노·리알 모두 아르헨티나 국기다. 리알은 1955년부터 스페인 대표로도 뛰었으므로 사이트 표에서는 열 이름을 `출신`으로 두고 아르헨티나로 적었다.

## 공동 7위와 자료 차이

- 네 골: 런토시 미하이(뵈뢰시 로보고)·군나르 노르달(밀란)·미셸 르블롱(랭스). 두 자료 일치.
- 알프레트 쾨르너(SK 라피트 빈): RSSSF 3골(형제 로베르트 쾨르너 1골 별도), UEFA 4골. 차이는 1956-01-18 빈 라피트-밀란 1-1의 페널티킥 골 주인이다. 표는 두 자료가 일치하는 9명까지만 싣고 본문에 차이를 적었다.
- 득점 시각은 두 자료가 1-2분씩 다른 경기가 있어 본문에 분 단위를 쓰지 않았다. 부다페스트 4-4 경기의 득점 순서는 기존 1955-56 편의 `후반 초반 랭스 4-1 리드`만 인용하고, 펄로타시 두 골의 순서는 단정하지 않았다.

## 사진

- `palotas-1955-goal.webp`: 푸슈카시 연구소(Puskás Intézet) 기사 「Palotás Péter 95」의 사진. 캡션 원문 `Palotás Péter (jobbra fehérben) győztes gólja az 1955. december 4-i Vörös Lobogó – Pécsi Dózsa (1–0) NB I-es mérkőzésen a Népstadionban`. 연구소 로고 워터마크가 있으며 사진 에이전시 워터마크는 아니다. 1200×575 원본을 WebP로 변환만 했다.
- MTK 공식 추모 기사의 초상은 307×164로 작아 쓰지 않았다. 블리아르의 Commons 사진(1979 파니니 스티커, 198×316)은 확보만 하고 본문 해상도가 부족해 쓰지 않았다(`rene-bliard.webp`는 저장소에 넣지 않음).
- 개별 권리 신호 없음. C등급, 조치 없음.

## 구조

- 득점 순위표는 원고에 쓰지 않고 `src/data/european-cup-scorers.json` + `renderTopScorers`(`data-european-cup-scorers="1955-56"`)로 만든다. 골 수 정렬, 공동 순위 계산, 국기 파일, 시즌 합계 초과를 빌드에서 검사한다.
- 시즌 읽기 동선(`reading-routes.ts`)에 05번으로 넣고 발롱도르를 06번으로 옮겼다.
